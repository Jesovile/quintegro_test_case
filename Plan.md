# Поведение системы

1. Пользователь submit заказ
2. Менеджер договаривается

Статусы заказов

1. New - положил в карзину
2. Waiting Payment - когда заказ еще не оплачен
3. Payment Proccess - этап когда пользователь уже оплатил, но мы не получили подтверждение от банка
4. In progess - Когда собираем товар(пока он еще у нас)
5. Delivery - Этап когда мы отправили пользователю
6. Done - Завершили заказ
7. Failed - Что-то случилось с заказом
8. Canceled by User - Отмененныен пользователем
9. Canceled by Company - Отменен компанией

# Идеальный флоу

Пользователь нажал оформить заказ -> Открываться форма с адресса, ожидаемое время достаки, телефон для связи, коментарий -> после нажатия далее, мы открываем форму с инфой о карте и вызываем API банка -> редирект обратно на карзину статусов.

Обновление статусов при обновлении страницы.
